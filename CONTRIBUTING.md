# Contributing

Contributions are welcome when they preserve the project's evidence-first approach.

- Do not submit copyrighted framework text unless redistribution rights are documented.
- Use synthetic data and fictional organizations in examples and tests.
- A proposed mapping must identify framework versions, mapping strength, rationale, source, and reviewer status.
- AI output must remain advisory and require human approval.
- Run `npm test` before opening a pull request.

By contributing, you agree that your contribution is licensed under the repository license.
